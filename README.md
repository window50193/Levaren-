# LÉVAREN Store

Railway'e hazır Node.js + Express mağaza.

## Çalışan özellikler
- Ürün kataloğu ve kategori filtreleri
- Ürün detay paneli
- Sepete ekleme / çıkarma / adet değiştirme
- Sepeti temizleme
- Sepet toplamı
- Checkout formu
- Sipariş oluşturma
- Hesabım / sipariş geçmişi
- Sipariş iptali
- Mobil menü
- Yumuşak geçişler ve responsive tasarım
- Yüklenen ürün fotoğrafları projeye dahil

## Railway
GitHub'a dosyaları yükledikten sonra Railway > New Project > GitHub Repository ile repoyu seç.
Railway `npm start` komutuyla çalışır. Port otomatik olarak `process.env.PORT` üzerinden alınır.

Not: Bu sürüm gerçek banka/kart tahsilatı yapmaz. "Kart" seçeneği sadece arayüz içindir. Gerçek ödeme için iyzico/PayTR/Stripe gibi bir ödeme sağlayıcısı ve kalıcı veritabanı ayrıca bağlanmalıdır.
